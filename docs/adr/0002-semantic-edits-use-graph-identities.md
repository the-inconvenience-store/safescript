# Semantic edits bind graph identities to a compilation revision

Operations address existing facts with `SemanticNodeId` values and use parent or sibling IDs as structural anchors, while a reproducible `SemanticRevisionId` binds source and program hashes, module and slot IDs, registry digest, compiler and language identity, and graph and edit schema versions. Node IDs remain formatting-insensitive facts rather than persistent document IDs; transformation provenance, not hidden UUID state, maps identities across accepted semantic edits.
