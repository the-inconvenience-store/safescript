# Semantic edit coverage is a language release invariant

Every source construct accepted by a SafeScript release must have semantic graph representation, editable boundaries, structural anchors, applicable primitive operations, preconditions, diagnostics, and conformance evidence. One private checked semantic model derived from TypeScript, contract, and lowering facts backs graph projection, capability discovery, edit resolution, lossless indexing, and provenance, while the public graph remains a derived non-executable product rather than a syntax tree or edit input.
